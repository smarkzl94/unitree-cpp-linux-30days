# 笔记目录

按「学前 / 学后 / 专题」分三块。

| 目录 | 放什么 | 何时写 |
|------|--------|--------|
| `knowledge/` | 预习讲义 `dayXX.md`（day01–30） | 学之前 |
| `daily/` | 每日知识卡 `YYYY-MM-DD.md` | 当天学完 |
| `recap/` | 周 / 月复盘，如 `week1-recap.md` | 每周收尾 |
| `topics/` | 跨天的专题手册，如 `cpp-stl-containers.md` | 需要时 |

另外三个是流程说明，不是笔记：`SYNC.md`（同步约定）、`email-setup.md`（邮箱）、本文件。

各天的 Linux 实操记录不在这里，写在当天代码目录的 `linux-notes.md`。
