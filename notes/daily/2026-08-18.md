# 2026-08-18 · Day 01 · MyString + Linux 目录/权限/man

## 今日目标
- C++：手写 `MyString`（拷贝 / 移动 / 析构，Rule of Five）
- Linux：`pwd` / `cd` / `ls` / `ls -la` / `man`；读懂权限 rwx

## 核心知识点（3–7 条）
1. 资源所有权：`MyString` 在堆上持有 `char*`，对象负责申请与释放（RAII）
2. 深拷贝：拷贝构造/赋值为对方新开一块内存，避免 double-free
3. 拷贝赋值先防自赋值 `s = s`，再释放旧资源再拷贝
4. 移动：偷指针，源置 `nullptr`，源必须可安全析构
5. `c_str()` 空串也要返回有效 C 串（`data_ ? data_ : ""`）
6. Linux：`-l` 是详细列表不是长路径；目录的 `x` 才能 `cd` 进去
7. `man`：空格翻页，`q` 退出，`/关键字` 搜索

## 代码要点 / API
- `week1-cpp-basics/day01-mystring/MyString.h` `.cpp` `main.cpp`
- 接口：默认/`const char*` 构造、五件套、`c_str()` / `size()` / `operator==`
- Linux 笔记：`week1-cpp-basics/day01-mystring/linux-notes.md`

## 易错点 / 坑
- `data_ = '\0'` 是把指针赋成空，不是写入空字符
- 拷贝赋值对 `other.data_ == nullptr` 不能 `strcpy`
- `MyString()` 与 `MyString("")` 都是空串，比较应走 `c_str()`
- man 里退出是 `q`，不是 `exit`

## 面试口述（2 题）
1. Q：深拷贝和浅拷贝差在哪？
   A：浅拷贝只拷指针，两对象共享一块堆内存，析构 double-free；深拷贝各自 `new[]` 一份内容。
2. Q：移动构造什么时候会被调用？`return` 局部对象时会发生什么？
   A：`std::move`、传右值/临时量时走移动。`return` 局部对象通常移动或被 RVO/NRVO 省略拷贝。
