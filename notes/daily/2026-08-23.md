# 2026-08-23 · Day 06 · RingBuffer + /proc

## 今日目标
- Linux：`/proc` 不是磁盘目录；看 MemAvailable；数逻辑核
- C++：定长环形缓冲，满时覆盖最旧

## 核心知识点（3–7 条）
1. 定长数组 + `head_`（读）+ `tail_`（写）+ 取模绕圈
2. `w==r` 分不清空满 → 另存 `size_`（本周做法）或牺牲一格
3. 满时策略：覆盖最旧（遥测）或拒绝（指令）。本周选覆盖
4. 构造时一次分配，热路径不再 `new`
5. `/proc` 是内核状态伪装成的文件，`cat` 等于当场问内核
6. 看剩余内存优先 **MemAvailable**，MemFree 会偏小
7. `nproc` 或 `grep -c "^processor" /proc/cpuinfo` 数整机逻辑核

## 代码要点 / API
- `week1-cpp-basics/day06-ringbuffer/RingBuffer.h` `main.cpp`
- `push` / `pop` / `size` / `full` / `empty`；满则覆盖最旧
- Linux：`cat /proc/cpuinfo` `cat /proc/meminfo` `nproc` `/proc/self`
- 本机 w64devkit 无 `/proc`，数字未采集

## 易错点 / 坑
- 空满不要只靠 `head_==tail_`，必须另存 size 或空一格
- 覆盖最旧时先挪 `head_` 再写 `tail_`
- 看内存别只盯 MemFree

2. Q：`/proc` 是什么？内存该看哪一行？
   A：内核状态伪装成的文件。看 MemAvailable。
