## 核心知识点（3–7 条）
1. `ps aux`：进程快照。a=all，u=用户显示格式（不是权限），x=含无终端进程
2. `ps -eLf`：线程快照。`-e` 所有进程，`-L` 列出 LWP，`-f` 完整格式
3. 同一进程多行：一行一条线程；PID 相同，LWP 不同，NLWP 是线程总数
4. 主线程 LWP 常常等于 PID
5. `top` 按进程直播；`top -H` 按线程直播；盯一个进程：`top -H -p <PID>`，`q` 退出
6. 堵在 `wait_and_pop` 时 CPU 很低 = 在等，不是没跑
7. `-elf`（小写 l）是 long，不按线程拆

## 易错点 / 坑
- `ps` 的 `x` 不是 `chmod +x`
- `-L` 和 `-l` 大小写搞反：命令能跑，看不到线程
- `top | grep` / `ngrep` 不是今天的用法；用 `top -H -p <PID>`
- Markdown 表格里 `|` 要写成 `\|`，否则命令列会被拆开

## 面试口述（2 题）
1. Q：`ps aux` 和 `ps -eLf` 差在哪？  
   A：前者一行一个进程；后者一行一条线程（同一 PID 可多行，看 LWP/NLWP）。都是快照。
2. Q：`top` 和 `top -H` 差在哪？  
   A：都是直播。默认按进程；`-H` 按线程，CPU 算到每条 LWP 上。
