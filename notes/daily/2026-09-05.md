## 核心知识点（3–7 条）
1. 进程隔离，跨进程要 IPC；同机才能 shm/pipe，跨机器走网络
2. `ipcs -m` = System V shm；`ls /dev/shm` = POSIX shm；`df -h /dev/shm` 看容量不是列文件
3. 匿名 pipe 无名字，看 `/proc/PID/fd` 的 `pipe:[inode]`
4. FIFO 有路径；POSIX/SysV shm 是共享的一页内存，要自己同步
5. 管道是字节流，循环读满 sizeof(帧)；父关写端子才读到 0
6. 今天做透一种即可（推荐 pipe）；htole/htobe 是跨机器字节序，本机可先不管

## 面试口述（2 题）
1. Q：`ipcs` 和 `ls /dev/shm` 各看什么？匿名管道呢？  
   A：ipcs 看 System V；/dev/shm 看 POSIX shm。匿名管道两边都没名字，看 /proc/PID/fd。
2. Q：同机父子怎么传一帧最简单？  
   A：pipe + fork；按 sizeof 循环读写；父 waitpid。
