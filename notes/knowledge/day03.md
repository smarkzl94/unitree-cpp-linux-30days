# Day03 · DynArray 与 vector 原理

日期：2026-08-20

## 为什么学这个
`std::vector` 是最常用容器；懂扩容与迭代器失效，才能在热路径上写出不踩坑的代码。

## 核心知识
1. **三指针模型（概念）**：begin / size 末尾 / capacity 末尾。
2. **扩容**：`size == capacity` 再 `push_back` 时，分配更大块（常 2 倍），移动/拷贝旧元素，释放旧块。
3. **均摊 O(1)**：单次扩容 O(n)，但均摊到多次 push 仍近似常数。
4. **迭代器/引用/指针失效**：扩容后旧内存释放，原先指向元素的迭代器全部失效。
5. **`reserve`**：预知大小时先预留，避免多次扩容。
6. **`emplace_back` vs `push_back`**：前者原地构造，少一次临时对象（视类型而定）。

## 易错点
- 循环中 `push_back` 后继续用旧迭代器
- 对 `vector<bool>` 特殊行为想当然（比特代理）
- 频繁在头部插入 —— 应用 `deque` 或别的结构

## 面试常问
- `size` 与 `capacity` 区别？
- 为什么扩容后引用会悬空？
- 如何减少扩容次数？

## 和宇树岗的关系
轨迹点、传感器批量数据、日志行缓冲常用 `vector`；实时路径上常 `reserve`。
