# Day04 · 优先级调度器与 STL 容器

日期：2026-08-21

## 为什么学这个
任务/事件按优先级处理在机器人软件里常见（告警 > 控制 > 日志）。练 `priority_queue` + 哈希索引。

## 核心知识
1. **`priority_queue`**：默认大顶堆；底层常是 `vector` + `heap` 算法。
2. **只能高效取堆顶**，不能任意改堆中元素的优先级。
3. **延迟删除**：堆里放「版本号/id」；真正弹出时若已过期则丢弃；用 `unordered_map` 存最新优先级。
4. **`unordered_map`**：平均 O(1) 查找；哈希冲突与自定义哈希需注意。
5. **比较器**：`Compare` 决定大小顶；lambda 可做比较器（注意类型）。

## 易错点
- 直接改 `priority_queue` 内部元素
- 忘记处理「同一 id 多次更新」导致堆里多个脏项
- 哈希表 key 用了会变的对象却没保证哈希稳定

## 面试常问
- 堆能 O(log n) 改任意元素吗？不能，通常怎么做？
- `map` vs `unordered_map` 如何选？
