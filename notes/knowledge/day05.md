# Day05 · Lambda 与 `<algorithm>`

日期：2026-08-22

## 为什么学这个
现代 C++ 用函数对象描述「策略」；算法库减少手写循环错误。

## 核心知识
1. **Lambda**：`[capture](params) -> ret { body }`。
2. **捕获**：`[=]` 值、`[&]` 引用、`[this]`、具名捕获；注意悬空引用。
3. **`std::function`**：可存储可调用对象，有类型擦除开销。
4. **常用算法**：`sort`、`find_if`、`remove_if`、`transform`、`accumulate`。
5. **谓词**：返回 bool 的可调用对象，用于过滤/查找。

## 易错点
- 捕获局部引用后 lambda 活得更久 → 悬空
- 在算法中修改正在遍历的容器结构
- 过度用 `std::function` 导致热路径开销
