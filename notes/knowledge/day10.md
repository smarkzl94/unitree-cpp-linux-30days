# Day10 · 死锁

日期：2026-08-27

## 为什么学这个
多锁系统（日志锁+队列锁+状态锁）很容易交叉加锁死掉。要会**制造、观察、修复**。

## 核心知识
1. **死锁四条件**：互斥、占有且等待、不可抢占、循环等待。
2. **典型模式**：线程 A 锁1再锁2，线程 B 锁2再锁1。
3. **排查**：`gdb` → `info threads` → `bt` 看各线程卡在哪把锁。
4. **修复**：
   - **固定加锁顺序**（全局约定 lock id 从小到大）
   - `std::scoped_lock(m1,m2)` 一次性锁多把（C++17，防死锁算法）
   - 减少锁数量 / 锁层级
5. **预防 vs 检测**：工程上以预防为主。

## 易错点
- 修复后不加压力测试就以为好了
- 忽略「锁顺序文档」导致后人再引入死锁

## 面试常问

- `scoped_lock` 解决什么问题？
