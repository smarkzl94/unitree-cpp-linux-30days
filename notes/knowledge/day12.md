# Day12 · 传感器生产者（定时数据流）

日期：2026-08-29

## 为什么学这个
机器人感知侧典型：固定频率采样 → 入缓冲。为 Hub 项目打基础。

## 核心知识
1. **数据帧**：时间戳 + 序列号 + payload（IMU/关节角模拟即可）。
2. **定频**：周期 T=10ms → 100Hz；`sleep` 只能近似，真实系统用定时器/时钟源。
3. **写入 RingBuffer**：满则按既定策略覆盖或丢弃。
4. **测量实际频率**：统计一段时间帧数 / 时间。
5. **时间戳单调性**：用稳态时钟（`steady_clock`）测间隔更合适。

## 易错点
- sleep 累计误差不管
- 时间戳用墙钟又拿去算延迟导致跳变
- 生产过快把控制线程饿死（需有界+策略）
