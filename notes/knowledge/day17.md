# Day17 · 进程：fork / exec / wait

日期：2026-09-03（建议 WSL）

## 为什么学这个
理解「进程」是 Linux 一切的基础；机器人里常有独立节点/工具进程。

## 核心知识
1. **进程 vs 线程**：进程有独立地址空间；线程共享。
2. **`fork`**：复制当前进程；返回两次（父=子 PID，子=0）。
3. **写时复制（COW）**：fork 后页先共享，写入再拷贝。
4. **`exec*`**：用新程序替换当前进程映像。
5. **`wait` / `waitpid`**：父回收子退出状态；不回收 → **僵尸进程**。
6. **典型模式**：父 fork → 子 exec 工具 → 父 wait。

## 易错点
- fork 后父子都继续跑复杂逻辑却不区分
- 忘记 wait 导致僵尸
- 多线程程序里乱 fork（只允许异步信号安全路径，复杂——了解风险）
