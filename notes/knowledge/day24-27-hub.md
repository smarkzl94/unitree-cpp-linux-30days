# Day24–27 · Telemetry Hub（综合项目知识）

对应日期：09-10 ~ 09-13

## 项目目标
模拟真机遥测链路：

```
传感器线程 --100Hz--> RingBuffer --> 控制/处理线程 --> TCP 上报最新状态
                              ^
                         Ctrl+C 优雅退出
```

## 分日焦点
- **Day24**：接通产线 + RingBuffer + TCP 发最新
- **Day25**：滤波或异常检测 + 可开关日志
- **Day26**：压测延迟/丢包，修 1 个性能点
- **Day27**：README、架构图、简单断线重连

## 核心设计知识
1. **只要最新**：发送端可只保留 latest frame，避免越积越多。
2. **线程职责单一**：产、消、网分离，用清晰队列/缓冲连接。
3. **背压**：网络慢时覆盖旧遥测，而不是无限队列。
4. **可观测**：频率、延迟、丢包打印或落盘。
5. **优雅退出**：统一 `running` 标志 + notify + join + close。
6. **断线重连**：client 循环 connect；server 接受新连接（简单版即可）。

## 面试怎么讲
「我做了个遥测中枢：固定频率模拟传感，环形缓冲控内存，控制线程做轻处理，TCP 推最新状态；压过延迟和丢包，并处理 Ctrl+C 与断线。」
