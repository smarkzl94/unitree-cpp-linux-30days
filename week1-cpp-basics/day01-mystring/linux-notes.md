## 今日命令


| 命令       | 作用                                          |
| -------- | ------------------------------------------- |
| `pwd`    | 打印当前工作目录                                    |
| `cd 路径`  | 切换目录；`cd ..` 上一级，`cd ~` 回家目录                |
| `ls`     | 列出当前目录下的文件/子目录名                             |
| `ls -la` | `-l` 详细列表（权限、所有者、大小、时间等）；`-a` 含隐藏文件（`.` 开头） |
| `man 命令` | 查看该命令的手册页                                   |


## `ls -la` 第一列（权限）

典型：`drwxr-xr-x` 或 `-rw-r--r--`

```text
类型  owner  group  others
 d    rwx    r-x    r-x
```

- 类型：`-` 普通文件，`d` 目录，`l` 软链接
- 三组权限：所有者 / 同组 / 其他人
- `r` 读 · `w` 写 · `x` 执行


| 权限  | 对文件     | 对目录          |
| --- | ------- | ------------ |
| `r` | 可读内容    | 可列出目录里有什么    |
| `w` | 可改内容    | 可在目录内增删改名字   |
| `x` | 可当作程序执行 | 可 `cd` 进入该目录 |


常见：`644` = `rw-r--r--`；`755` = `rwxr-xr-x`（脚本/目录常用）。
