# Day02 · Linux 笔记（ps / top / kill）

日期：2026-08-19  
环境说明：概念学习 + 在线终端练习（本机暂无 WSL）

## 今日命令

| 命令 | 作用 |
|------|------|
| `ps` | 列出进程的一张快照，不会自己刷新 |
| `ps aux` / `ps -ef` | 详细进程列表（PID、命令名、谁在跑等） |
| `top` | 持续刷新 CPU/内存；按 `q` 退出 |
| `kill PID` | 默认发 SIGTERM：请进程退出，可以做清理 |
| `kill -9 PID` | 发 SIGKILL：内核直接干掉，来不及析构/关文件 |

## `ps` vs `top`

- `ps`：拍一张名单（快照）
- `top`：连续刷新（直播）
- 退出 `top`：按 `q`（不是 `exit`）

## `kill` vs `kill -9`

- `kill`（默认）：SIGTERM，进程能走退出逻辑
- `kill -9`：SIGKILL，不能清理
- 先不用 `-9`：给进程机会关设备、写完文件；乱强杀可能留下半开句柄

## 口述自检

1. `ps` 快照，`top` 持续刷新。
2. `kill` 像「请析构」；`kill -9` 像拔电源。
