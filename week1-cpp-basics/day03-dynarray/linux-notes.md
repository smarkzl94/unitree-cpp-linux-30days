# Day03 · Linux 笔记（重定向 / 管道 / grep / find / wc）

日期：2026-08-20  
环境说明：w64devkit 的 sh（不要用 PowerShell 的 `find`）

## 今日命令

| 命令 | 作用 |
|------|------|
| `>` | 把 stdout（正常输出）重定向到文件，**覆盖** |
| `>>` | 把 stdout 重定向到文件，**追加** |
| `2>` | 把 stderr（报错）重定向到文件，覆盖 |
| `2>&1` | 把 2 接到 1 **此刻**所指的地方；要两边进同一文件：先 `> 文件` 再 `2>&1` |
| `\|` | 管道：左边的 stdout 接到右边命令的 stdin |
| `grep` | 在文件**内容**里找匹配的行 |
| `grep -n` / `grep -R` | `-n` 给匹配行加上**行号**（不是只搜几行）；`-R` 递归搜子目录 |
| `find . -name "*.cpp"` | 按**文件名**找路径 |
| `wc -l` | 统计行数；管道里喂的是文件名，数的就是文件个数 |

## `>` / `>>` / `2>`

- `>`：覆盖 stdout；手滑接到已有文件会把原内容清空。
- `>>`：追加 stdout，不覆盖已有内容。
- `2>`：覆盖 stderr。追加报错用 `2>>`。

## `|` 和 `>`

- `>` 接到**文件**；`|` 接到**下一个程序**。
- 管道默认只管 stdout，不管 stderr。报错也要进管道：`2>&1 |`。

## `grep` vs `find`

- `grep`：搜文件**内容**。
- `find`：搜**文件名/路径**。
- 常用：`find . -name "*.cpp" | xargs grep -n "operator="`

## 上机数字

在 `week1-cpp-basics/` 下（本机 w64devkit）：

- `find . -name "*.cpp" | wc -l` → **4**（四个 cpp 文件，不是代码总行数）
- `grep -R "TODO" . | wc -l` → **18**（匹配到的 TODO 行数）

## 口述自检

1. `>` 覆盖 stdout，`>>` 追加 stdout，`2>` 覆盖 stderr。
2. `|` 接到下一个命令，`>` 接到文件。
3. `grep` 找内容，`find` 找文件名；`find ... | wc -l` 数的是文件个数。
