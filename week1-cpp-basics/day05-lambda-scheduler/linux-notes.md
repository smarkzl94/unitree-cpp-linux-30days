## 今日命令

| 命令 | 作用 |
|------|------|
| `ln a b` | 硬链接：`b` 和 `a` 指向同一 inode |
| `ln -s a b` | 软链接：`b` 里存着通往 `a` 的路径 |
| `ls -li` | `-l` 详细列表，`-i` 看 inode 编号 |
| `ls -l` 看软链 | 第一位是 `l`，箭头指向目标 |
| `tree` 或 `find . -maxdepth 2` | 看目录结构（没有 tree 用 find） |
| `du -sh .` | 当前目录**合计**占多少盘（`-s` 合计，`-h` 好读） |
| `du -h --max-depth=1` | 下一层每个子目录各占多少 |

## 软链 vs 硬链

- **硬链**：同一个 inode 的第二个名字。删掉原文件名，只要还有硬链，内容还能读。
- **软链**：存的是路径。原文件删了，软链还在但**悬空**，读会失败。
- 硬链一般不能链目录、不能跨分区；软链可以。
